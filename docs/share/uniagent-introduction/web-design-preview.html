对话接力
01
对话可以带走，工作接着往下做

Codex 额度用完，换 接着聊。

Agent 之间支持导入对话。Codex 额度耗尽时，把当前 Session 导入 ，沿着已有需求、讨论和执行记录继续推进，不必重新交代背景。

底层如何接上上下文
  1. 1
    读取原会话

    将可读取的历史消息和执行记录整理成统一事件。

  2. 2
    转换为目标格式

    写入 的原生会话格式，生成独立的新会话。

  3. 3
    恢复并继续对话

    由目标 CLI 读取历史，再接收你的下一条消息。

当前支持 Codex、Claude Code 之间的跨 Agent 分叉。跨协议会转换可用的对话上下文，部分底层状态无法迁移；目标 Agent 需已登录且有可用额度。

多 Agent 相互调用
02
把另一个 Agent，变成当前任务的协作搭档

通过 MCP，Agent 可以相互调用。

Codex 可以把实现交给 ，再请 Claude Code 审查。各自继续使用原生 CLI，UniAgent Public 负责发现协作对象、路由任务，并把结果送回发起方。

一次跨 Agent 调用，经过哪些环节
  1. 1
    加载 MCP

    UniAgent Public 在 CLI 启动配置中接入本地 MCP 服务。

  2. 2
    发起工具调用

    调用方选择 Agent 或角色，提交任务及所需上下文。

  3. 3
    目标会话执行

    UniAgent Public 创建或续接目标 Session，由对应 CLI 执行。

  4. 4
    返回结果

    拿到状态与结果，调用方继续分析、追问或完成交付。

例如

Codex 拆解需求 → 完成实现 → Claude Code 审查 → 结果回到发起方

可等待目标任务结束后取得回复，也可先取得任务引用，再查看状态与结果。调用目标、运行中补充消息等能力，以各 Agent 实际支持情况为准。

飞书通知与远程对话

任务继续跑，
进展随身看。

在设置中一键授权或手动绑定飞书机器人，按引导选择私人聊天或群聊接收通知，再配置新建会话参数。一个话题对应一个任务，离开电脑也能查看进展、回答问题、继续对话。

  • 进展主动到达，不必守着屏幕运行状态、关键回复与交付，汇到同一话题；当前飞书轮次也可回传图片和文件。
  • 在手机上回答，任务接着推进处理 Agent 提问与权限请求，补充要求；在 App 回答后，飞书卡片同步显示处理状态。
  • 从手机发起下一项任务选择项目、Agent 与模型，直接从飞书开始；已有对话可用 /model 切换模型与思考深度。

普通会话与个人助手分别绑定独立的飞书机器人。电脑须保持运行和联网，UniAgent Public 与对应 CLI 需可用；推送时机遵循通知设置，交互能力因 Agent 而异。

为日常开发准备

从任务到交付，
常用工具都在手边。

从独立代码目录、上下文与任务控制，到阅读评论和改动审阅，让每一步都有清晰的入口。

空间与需求上下文

按空间、项目和需求组织会话，关联主目录、附加目录与需求资料；固定角色和任务预设复用常用执行配置。

Diff 审阅与文件预览

查看 Git 改动与并排 Diff，预览图片、Markdown 和 HTML；图片可放大、滚轮缩放，放大后拖动查看细节。

Skills、MCP 与工具能力

用 / 查找原生命令、技能、插件与 MCP；在能力中心查看清单，在支持范围内比较、选择并同步配置。

队列、定时任务与提醒

执行中追加或编辑待发消息，管理受支持的定时任务。Dock 角标按未读会话计数，提醒你处理提问、审批与任务结果；打开对应会话阅读后清除。

账户额度与用量

集中查看可用 Agent 的账户额度、Token 与上下文；原生日视图按小时统计，已有用量缓存先展示并在后台刷新。DeepSeek 每轮费用按官方峰谷价估算，实际计费以服务方为准。

全窗阅读与评论反馈

全窗阅读长回复与 Markdown 文件，按目录定位、选中正文添加评论；文件评论同步回当前会话，汇总后发送给 Agent。

会话工作树与并行开发

新任务可从空间仓库的选定提交创建独立 Git 工作树，执行目录随会话续接和分叉保留；专家团成员共享团队的工作树。

Goal、Plan 与上下文管理

使用受支持的原生目标、计划与审查模式；按需压缩上下文，分叉会话或开启侧边对话。具体入口随 Agent 能力显示。

异步问答与执行控制

从待回答卡片定位提问，展开完整问题，提交结构化回答；审批、运行中补充要求与中断，在支持的 Agent 中直接处理。

工作树默认不启用；新建时仅包含选定基准提交，未提交改动、依赖和本地配置不会自动复制。附加目录仍共享原路径；归档或删除会话不会自动清理工作树。

常见问题

开始前，你可能想了解。

它会替代我原来的 Agent 账号或订阅吗？

不会。UniAgent Public 统一界面与协作体验，执行仍基于各家 CLI 与模型服务。安装、登录、额度和计费沿用对应服务；协作通常涉及额外模型调用。

每个 Agent 的能力完全一样吗？

不一样。Codex 提供较完整的工作台能力；Claude Code、ZCode、MiniMax Code、Kimi Code、Grok、DeepSeek Harness 标记为 Beta。跨 Agent 分叉支持 Codex、Claude Code；专家团还支持 ZCode。模型、附件、权限与会话操作以当前运行时为准。

个人助手的记忆和聊天记录有什么区别？

聊天记录保存每次对话的原文；长期记忆保存供后续对话使用的稳定事实与偏好。助手可用搜索回看自己的历史，你也可以编辑记忆、查看和恢复文档版本。启用新对话命令不会清除长期记忆。

本地优先，是否代表所有内容都不会联网？

不是。项目、会话与配置在本地管理，但使用在线模型时，相关请求会发送到模型服务；启用飞书或微信后，对应渠道的会话内容会发送到该服务。
